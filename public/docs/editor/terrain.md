# 地形编辑

地形 = **Terrain 节点**（场景中的渲染/碰撞载体）+ **`.terrain` 资产**（高度数据）+ **`.terrainmat` 地形材质**（4 层纹理混合）。三件事分别在检查器、资产面板、绘制模式里完成。

## 创建地形

1. 层级「添加节点 ▸ 地形 ▸ Terrain」创建地形节点；
2. 资产面板右键「**新建地形**」（默认程序化山地模板）生成 `.terrain` 资产；
3. 选中地形节点，检查器 Terrain 卡片**绑定**该资产。

## 程序化地形（Terrain 检查器）

绑定 `.terrain` 后，检查器提供整套程序化参数，改完「保存回 .terrain」落盘：

| 参数组 | 字段 |
| --- | --- |
| Heightfield | seed（可随机——同参数同地形，确定性生成）、尺寸、网格密度、起伏 heightScale、频率、分形层数 octaves、频率步进 lacunarity、振幅步进 gain、导数阻尼 erosion、域扭曲 warp、谷地压平 valleyBias、海平面、热侵蚀 talus（+passes） |
| Surface | 草地 / 岩石 / 积雪三色（烘焙为顶点色） |

**确定性**：程序化生成由 seed 保证——同参数必出同地形，适合团队协作与版本管理。

## 地形材质与 Splatmap

- 资产面板右键「**新建地形材质**」创建 `.terrainmat`：4 个纹理图层 + splatmap 权重图 + 全局 PBR 参数；
- 地形节点绑定材质后，检查器「**生成 Splatmap**」按海拔/坡度烘焙 RGBA 权重纹理（写回 `assets/…_splat.png` 并更新材质引用）——**这是进入绘制模式的前置**（手刷权重需要一张初始权重图）。

## 数字地形数据（DEM 导入）

想用真实地理高程（DEM/DTM/DSM）作底，用检查器的 **Digital Terrain Data** 卡：

| 项 | 说明 |
| --- | --- |
| 导入格式 | `.asc`（Esri ASCII Grid，标准交换格式）、`.hgt`（SRTM 大端 int16 方阵）、`.pgm`（P5/P2 灰度高程，16 位大端）、`.xyz` / `.csv`（高程点/点云，散点桶平均栅格化 + 平滑回填） |
| 数据形态 | 解析为归一化 0..1 高度网格（上限 513²），**base64 内嵌进节点**——预览/导出不依赖源文件 |
| 与程序化的关系 | 导入数据替代程序化分形作**基准高度**：最终高度 = 归一化数据 × Heightfield 的 heightScale（即垂直夸张系数）；雕刻层照常叠加 |
| 一致性 | 碰撞 heightfield / 导航烘焙 / 脚本采样全链路自动一致（同一条烘焙出口） |
| 清除数据源 | 回退程序化分形；卡片回显源文件/格式/网格/高程范围（原单位） |

## 绘制模式（雕刻与权重刷）

入口：视口「**绘制**」按钮（或等价命令）。前提：**场景视图 + 地形已绑材质并生成 Splatmap**；再执行一次或点「退出」结束。激活期间变换工具（W/E/R）失效。

浮动笔刷面板两个页签：

| 页签 | 笔刷 |
| --- | --- |
| 雕刻 | **抬升 / 压低 / 压平 / 平滑**——写高度偏移层（经撤销系统，可回退） |
| 权重 | 材质**层 1~4** 各一个笔刷（层色取自材质层色）+ **擦除**（该层权重清零并转移回其余层） |

- 笔刷**大小 0.5~40m**、**强度 5~100%**，贴地圆环光标实时预览覆盖范围；
- 交互接管：激活期间左键 = 笔刷（轨道相机的左键旋转临时禁用；右键平移 / 滚轮缩放保留）；
- 笔刷会话写在 splatmap 工作缓冲上，抬笔提交（100ms 节流）回 `.terrainmat` 引用的 splatmap 资产，引擎缓存随之刷新——**绘制结果随资产保存，场景间可复用**。

## 脚本侧

- 贴地查询：`TerrainNode.sampleHeight / sampleSlope`（角色贴地行走、坡度判定等，模板见 SDK 文档）；
- 运行时烘焙：程序化高度在产物中按同一参数烘焙，导入数据版直接用内嵌网格。

## 建议工作流

1. 程序化调大形（seed + heightScale + 侵蚀）或导入 DEM；
2. 绑定地形材质 → 生成 Splatmap；
3. 进绘制模式：先雕刻（局部抬升/压平做出道路与平台），再刷权重（草地/岩石/积雪分区）；
4. 节点 Transform 照常可用（整块地形移动/缩放）；需要物理碰撞时给地形配碰撞（heightfield 与渲染同源，自动一致）。
