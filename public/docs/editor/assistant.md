# AI 助手

AI 助手是对话式的**创作员工**：你说想要什么，它在项目里干活——建场景、摆节点、写脚本、调参数，每一步可见可审计。这一页讲助手面板的使用；它为什么可靠（权限门控、执行对账、写前校验）穿插在各节。

## 打开与窗口

- 入口：**首页**标题栏「✦ 助手」按钮；
- 全局单例**浮动窗口**（无边框、可拖拽、位置记忆）；点隐藏 ≠ 关闭——面板状态与对话保留，再点回来接着聊。

## 项目工作区

- 左栏是项目列表：**项目目录即工作区**——点击切换对话与资产上下文，**不需要在编辑器里打开该项目**；清单只读自首页项目管理页（项目的增删在项目管理页维护）；当前编辑器打开的项目带绿点标识；
- 会话按项目根隔离：每个项目有自己的会话列表，互不串台。

## 会话

- 聊天头部会话切换器（会话名 ▾）列出当前工作区全部会话，点击切换、× 删除；「＋ 新建会话」开新对话；
- 首条用户消息自动成为会话名。

## 对话

- 输入框 **Enter 发送、Shift+Enter 换行**；回复流式输出；
- 助手执行动作时显示 ⚙ 工具芯片（如"列出场景""写入脚本"）——**每个动作都是真实的工具调用**：助手宣称完成的事都有执行记录对账，没实际动手的"完成"会被自动拉回重做；
- **@插入文件**：输入框左侧 @ 唤起资产搜索，选中的文本资产（≤512KB；二进制不支持）以引用块插入输入框——让助手基于指定脚本/材质/场景文本干活。

## 能力与边界（实事求是）

| 场景 | 行为 |
| --- | --- |
| **项目未在编辑器打开** | 文件级操作照常：列出/读取/写入项目文件（含场景文本、脚本、材质），自动建父目录、拒绝路径穿越 |
| 节点级操作（选中/添加/修改节点）、预览控制 | 需要**编辑器会话**——项目未打开时助手会提示"没有活跃的编辑器窗口"，并改用文件级工具达成目的 |
| 新建项目等敏感操作 | 走权限门控，可能请求确认 |
| 危险/越权动作 | 助手与外部控制端**共用同一份工具权限清单**——首页「开发者服务 ▸ 工具权限」里关掉的工具（如写入资产、新建项目），助手调用同样被拒 |

写入场景/着色器前会按引擎同款规则**校验**——写坏引擎打不开的内容会被拒绝并把原因回喂给助手重写，不会弄坏项目文件。

## 设置（左栏底部「⚙ 设置」）

右栏就地切换两页：

- **智能体卡片**：人设与行为预设——名称/头像人设描述、自定义提示词、开场白、标签、**模型与温度覆盖**（卡片可覆盖全局模型）；卡片支持导入导出 JSON 分享；
- **供应商**：OpenAI 兼容接口配置——Base URL、API Key、模型（可拉取模型列表作候选，也可手填）。**API Key 仅保存在本机**，不随项目/共享外发。

无供应商配置时聊天区显示引导卡片，配好即可用。

## 典型用法

- 「给场景加三个不同颜色的点光，摆成一排」——助手列场景、加节点、调参数，一步不落地执行并在编辑器里可见（项目需在编辑器打开）；
- 「帮我看下 src/player.ts 为什么不动」——@插入或自动读文件，定位问题并给出（或直接落地）修改；
- 「新建一个旋转马达脚本挂到选中的箱子上」——生成脚本、写盘、挂载组件，检查器里即可调属性。
