# 预览与构建

## 网页预览

工具栏切到「预览」：把当前场景导出为独立网页，经本地静态服务在内嵌 iframe 中运行（与编辑器画布无关，**真实运行时语义**——所见即发布效果）。

### 预览工具条

| 按钮 | 行为 |
| --- | --- |
| 刷新 | 重新导出当前编辑内容并重载（保存当前场景 + 脏脚本 → 重编译 → 重载 iframe；服务保持运行，按需读盘） |
| 在浏览器打开 | 用默认浏览器打开当前预览地址（同一本地服务，可用于 DevTools 调试） |
| 调试 | 切换运行时统计面板（性能读数/能力探测；运行时内嵌页面在 iframe 聚焦时也可按 **F3** 唤出） |
| 停止预览 | 停止服务释放端口；离开预览页签自动停止 |
| ✕ | 关闭预览页签返回场景 |

### 导出与运行

- **进入预览**：自动导出（保存当前编辑场景 + 编译全部脚本 + 打包运行时）并启动服务；
- 导出内容写入项目下临时目录（`<项目>/.tmp/web-preview`），本地静态服务监听系统分配的临时端口（每个编辑器窗口独立服务，多项目预览互不串台；外部浏览器可访问）；
- 导出文件 = three 运行时 + 播放器（player）+ `config.json`（项目配置）+ 全量编译的 `src/**.js`（单脚本编译失败跳过并在控制台告警）；
- 可选运行时按项目配置按需打包：物理引擎（启用开关 + 所选引擎）、WebGPU 构建（渲染后端为 WebGPU/自动时，约 670KB，不可用时播放器自动回退 WebGL2）；
- 预览页的 console 与错误经 postMessage 转发到编辑器控制台（前缀 `[预览]`；构建勾选「调试模式」时产物同样转发）。

### 设备仿真

预览工具条提供设备仿真：内置 iPhone SE / iPhone 14 / iPhone 15 Pro / 安卓 360×800 / Pixel 7 / iPad 等机型（可切横竖屏）、自定义宽高与 DPR（1~4）；缩放滑条 25%~200% + 「适应」一键适配。设备设置按项目记忆。配合「屏幕方向」「缩放模式」项目设置可完整验证移动端适配效果。

## 构建导出

工具栏「构建」打开构建面板，把场景打包为可部署产物。

### 渠道

| 渠道 | 状态 | 产物去向 |
| --- | --- | --- |
| Web | 支持 | `<项目>/build/web/`，纯静态文件 |
| 微信小游戏 | 支持（真机实测跑通） | `<项目>/build/wechat/`，用微信开发者工具打开即验 |

两个渠道共用「构建场景 + 主场景」的选择（默认全选、主场景必须在其内，运行时可用 `?scene=场景名` 切换入口场景），构建前自动保存当前编辑场景与全部脏脚本（按磁盘内容构建），缺失资产跳过并列在结果区。

### 通用配置

| 项 | 说明 |
| --- | --- |
| 构建场景 | 多选项目内 `.scene`；须指定**主场景**（产物入口加载的场景，必须在所选场景内） |
| 调试 / 发布模式 | 二选一。发布 = 资源 uid 重命名 + 引用重写 + JSON 压缩（产物更小、路径不可读）；调试 = 保留可读路径与日志转发，便于排查 |

### Web 渠道配置

| 项 | 说明 |
| --- | --- |
| 页面标题 | Web 页面 `<title>`（默认项目名） |
| 导出模板 | 可多选；首个生成 `index.html`，其余生成 `index-<模板>.html`；多文件与单页模板不能混选（混选自动切换并提示）；支持 exe 旁 `public/exports/web` 的用户自定义模板 |
| 资产 gzip | 归档资产（多文件写 `assets.gzip`；单页 base64 内联）；可配 gzip 资源远程基址（空 = 本地读取） |
| CDN 模式 | 渲染运行时（three.js）不内嵌，从配置的 CDN 地址在线加载；未填地址时仍内嵌并黄字警告 |

产物为纯静态文件，可直接部署到任意静态服务器（或对象存储 + CDN）。产物内资产读取顺序：内联 gzip 包 → 内联资产表 → `assets.gzip` 归档 → 磁盘文件。

### 微信小游戏渠道配置

| 项 | 说明 | 默认 |
| --- | --- | --- |
| AppID | 小游戏 appid；留空走「上次构建产物继承 > 体验用 touristappid」链（写入 `project.config.json`，开发者工具可直接预览） | 继承链 |
| 屏幕方向 | 竖屏 / 横屏（写入 `game.json` 的 `deviceOrientation`） | 竖屏 |
| 分包加载 | 启用后文件化二进制资产按体积贪心分入 `pkg-N` 分包；**单分包体积上限 1~4MB** 可调。入口 `game.js` 在启动前并行预加载全部分包、计数归零才进游戏（单个分包加载失败仅告警、按资产缺失降级；基础库 <2.1.0 无 loadSubpackage 时自动跳过预加载直接进游戏）——这是主包 4MB 体积限制的解法 | 关 |
| 多线程加速 | 物理 + 动画进 Worker 线程（`workers/` 目录随包 + `game.json` 声明）。设备差异大故为**勾选项**：当前真机仍自动回退主线程运行（结果一致、只损失加速），勾选实际收益在开发者工具模拟器；回退原因可在诊断面看到 | 关 |
| 真机诊断 | 随产物内嵌屏上诊断模块（能力探测/物理音频 Worker 里程碑读数，模态弹窗展示）。运行期经 storage 开关显式唤出，不弹窗打扰玩家 | 关 |

### 微信产物形态与上手

`build/wechat/` 内容：

| 文件 | 内容 |
| --- | --- |
| `game.js` / `game.json` / `project.config.json` | 平台入口与配置（入口先同步诊断开关 → 预加载分包 → 再加载引擎） |
| `code.js` | 运行时单文件（引擎 + 播放器 + 桥接层，CJS 形态） |
| `data.js` | 场景与配置数据（文本类全内联） |
| `assets/<hash>` | 二进制资产原始字节落盘 |
| `pkg-0…N`（启用分包时） | 二进制资产分包 |
| `workers/`（勾选多线程时） | 物理/动画 Worker 包 |

上手流程：微信开发者工具 → 导入 `build/wechat` 目录 → 工具内预览/真机预览（扫码）→ 上传发版。2D 音频、Draco 压缩模型、分包资产读取均经真机验证；Draco 解码器随包内联（无需外链）；Basis 纹理压缩微信渠道暂不支持。

**真机排障提示**：预览卡片有缓存，进错卡片=跑旧包——判旧包看导出目录修改时间与入口版本号；真机上以「模态弹窗读数」为最可靠的诊断通道（控制台与 toast 在真机上均不可靠）。

### 构建结果区

面板底部显示结果摘要（单页/多文件 · gzip · 发布 · CDN · 模型转 bin 数量 · 场景数 · 资产数 · 主场景，微信渠道为分包/Workers 摘要）与缺失资产列表；按钮：打开构建目录 / 预览（起本地静态服务服务构建产物，iframe + 在浏览器打开 + 停止；微信渠道无此按钮——平台语义需在开发者工具内验证）/ 开始构建。

配置随项目保存在项目根 `build.config.json`（channel / scenes / mainScene / 各渠道选项），重开面板读回，旧配置兼容。

### 发布模式细节

勾选后构建做三件事：资源文件名改为内容 uid（防止路径探测、利于长缓存）；场景/材质/预制体内的全部资产引用同步重写；JSON 压缩去空白。调试模式则保留可读路径与日志转发，便于排查线上问题。

## 局域网共享（桌面端）

工具栏「共享」：把当前项目按 Web 单页 + gzip 构建到临时目录并发布到局域网托管——同一网段的设备扫码/输地址即玩，无需部署。首页「共享」分区可查看/启停/删除发布条目、看访问统计；共享服务可配置端口、网卡、口令、是否允许下载源文件。白板也能以同样方式发布为局域网页（见[白板](whiteboard.md)）。

## 开发者服务（桌面端）

首页「开发者服务」分区提供**本地控制服务器**（TCP 换行分隔 JSON + MCP 端点，默认端口 39100）：编辑器窗口执行命令（场景读写、节点增删改、资产、预览截图等），可配置端口与工具权限（约 19 个工具开关、逐个启停）、复制 MCP 配置接入外部 AI/工具链。详见[项目管理 › 开发者服务](projects.md)。
