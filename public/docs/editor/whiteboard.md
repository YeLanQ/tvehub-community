# 白板

白板是一个**全局单例窗口**（不随项目）：矢量画板，用于示意草图、流程梳理、分镜板与轻量演示。文件为自包含 `.svg`，可再导入、可发布到局域网放映。

## 打开与画布

- 入口：首页「白板」分区——新建白板，或从列表打开指定文件（删除也只在此分区）；
- **导航**：滚轮以光标为锚缩放（0.05~20 倍）、空格/中键拖拽平移、「适应画板取景」一键回整板——没有独立的缩放工具按钮；
- **画板尺寸**：标题栏下拉选择（预设与项目「设计分辨率」同源）或自定义 1~8192。

## 工具（底部浮动条）

| 工具 | 键 | 操作 |
| --- | --- | --- |
| 选择/移动 | V | 点选/框选、拖动、控制柄缩放 |
| 矩形 / 椭圆 / 直线 | R / O / L | 拖拽绘制 |
| 铅笔（自由笔） | P | 按住绘制 |
| 钢笔 | B | 单击 = 直角点、拖拽 = 曲线点；Enter 结束开放路径、双击闭合、Esc 取消 |
| 文本 | T | 点击落点，在右侧属性面板输入内容 |

- 线条粗细滑动条 1~24px（直线/铅笔/钢笔激活时显示）；
- **没有橡皮工具**：删除 = 选中后 Delete（曲线选中锚点时优先删锚点）；
- 颜色与填充在右侧**属性面板**：填充/描边色、「无填充」勾选、**图片填充**（data URL + cover / contain / stretch / tile 四种适配）——图片不是独立元素，而是形状的填充方式；
- 撤销/重做：Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y（快照栈上限 100，连续编辑自动折叠为一条）。

## 图层

右侧面板「图层」页签：新建 / 删除 / 重命名 / 可见性 / 锁定 / 不透明度 / 拖拽排序。元素归属于图层，图层顺序即绘制顺序。

**放映模式复用图层**：一页 = 一个可见图层（见下文），把不同阶段的示意图分到不同图层即可当幻灯片用。

## 文本富文本语法

文本内容本身就是标记源——`[b]粗[/b]` 风格标签：

| 语法 | 效果 |
| --- | --- |
| `[b]…[/b]` `[i]…[/i]` `[u]…[/u]` | 粗体 / 斜体 / 下划线 |
| `[color=#ff6600]…[/color]` | 局部着色 |
| `\[` | 转义输出字面 `[` |

导出为嵌套 tspan，外部 SVG 阅读器同样生效。

## 文件管理

| 动作 | 入口 | 行为 |
| --- | --- | --- |
| 新建 | 首页「新建白板」或窗口内新建 | 重置空白文档（保留画板尺寸），默认名「未命名.svg」 |
| 打开 | 首页列表 | 读取解析；解析失败保持原文档并提示 |
| 保存 | **仅手动** Ctrl+S / 保存按钮（脏标记圆点） | 校验名称 → 自动补 `.svg` → **防同名覆盖**（大小写不敏感比较，同名拒绝）→ 写盘 |
| 重命名 | 标题栏名称输入框改后保存 | 写新文件 + 删旧文件 + 元数据迁移（"改名后保存即重命名"） |
| 删除 | 仅首页白板分区 | 确认框 → 删除文件与元数据 |

- 保存名校验：仅字母/数字/汉字/空格/`._-`，拒绝路径分隔与 `..`；
- **元数据**（标签 / 归档 / 创建与更新时间）存在应用配置里，跨窗口同步；首页列表支持搜索、标签筛选、归档开关；
- 存储位置：全局白板目录（便携版 = exe 同级 `data/whiteboard/`；安装版在系统应用数据目录），不随项目。

## 文件格式

- 白板 `.svg` **自包含**：正常 SVG 图形 + 完整文档模型（图层/元素/动画）以 JSON 存在根节点 `data-tve-doc` 属性里——自己写的文件**无损回读**（图层、锁定、动画全保留）；
- 外部 SVG 可导入：走 DOM 兜底解析（渐变/图案填充等高级特性降级为近似形态）；
- 元素类型六种：矩形/椭圆/直线/铅笔/路径/文本；动画挂在元素上（位移/透明度/填充三种，导出为内嵌 CSS 动画，外部浏览器也能播）。

## 放映（画布内模式）

- **一页 = 一个可见图层**；入口：画布左下放映条 ▶/■、上一页/下一页（页码循环）；
- 切换动画：左右平移 / 上下平移 / 渐入渐出 / 层叠（约 0.5s）；播放模式 自动（间隔 1~60s）/ 手动；
- 放映中：`← → PageUp PageDown` 翻页、`Esc` 退出；图层面板选层 = 直接跳页；
- 放映从当前活动图层起播。

## 共享发布（局域网）

标题栏「共享」：把白板打成**自包含站点**发布到局域网托管——

- `index.html`：SVG 内联的放映页（零外部请求，扫码即看，打开时停在作者当前页）；
- `board.svg`：可再导入编辑的源文件；
- `board.json`：放映元信息；
- 同一文件再次共享 = **原地更新**（访问者刷新即最新）；「下载源文件」入口受共享配置的"允许下载"开关控制；
- 首页「共享」分区统一管理发布条目（见[项目管理 › 共享](projects.md)）。
